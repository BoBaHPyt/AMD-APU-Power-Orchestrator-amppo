# AMD APU Power Orchestrator (amppo)

Легковесная идиоматичная системная утилита на Rust для тонкого управления питанием, лимитами и частотами процессоров AMD Ryzen (архитектура **Zen 4 / Hawk Point** и аналогичные APU) в Linux. 

Проект разработан как более точная, предсказуемая и эффективная альтернатива стандартному `power-profiles-daemon` (PPD), предоставляя прямой контроль над интерфейсами ядра `sysfs`.

## 🚀 Особенности и архитектура

- **Zero-Cost Abstractions**: Написан на чистом Rust без использования тяжелых внешних библиотек и лишних аллокаций памяти в куче (heap) внутри циклов.
- **Атомарное управление GPU**: Учитывает особенности транзакционной модели драйвера `amdgpu`, отправляя пачки команд разгона/даунклокинга единым системным вызовом перед коммитом (`c\n`).
- **Безопасная валидация**: Перед записью профиля утилита проверяет доступность регуляторов частот (`scaling_available_governors`) и аппаратных предпочтений энергоэффективности (`energy_performance_available_preferences`), защищая систему от некорректных конфигураций.
- **Фокус на APU AMD**: Код оптимизирован специально для мобильных процессоров со встроенной графикой Radeon. Никакого лишнего мусора для Intel или Nvidia.

## 💻 Совместимость и тестирование

- **Протестированное железо:** AMD Ryzen 7 **8845HS** (Radeon 780M / Hawk Point).
- **Ожидаемая совместимость:** Все APU AMD Ryzen поколений Phoenix/Hawk Point (серии 7040/8040) и новее.
- **Поддерживаемые ядра Linux:** Протестировано и полностью работает на ядрах **v6.x** и **v7.x** (с активным драйвером `amd_pstate` и параметрами ядра `amd_pstate=active` и `amdgpu.ppfeaturemask=0xffffffff`).

## 🛠️ Разработка

Для сборки проекта необходим установленный Rust-тулчейн (Cargo) и права суперпользователя на целевой машине (для доступа к `/sys`).

### Сборка:
```bash
cargo build --release
```

### Запуск текущей версии ядра (требуется sudo и параметры ядра `amd_pstate=active` и `amdgpu.ppfeaturemask=0xffffffff`):
```bash
make install
sudo nano /etc/amppo/config.json
./target/release/amppo-cli <start> <toggle>
```
